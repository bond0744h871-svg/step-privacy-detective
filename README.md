# STEP 小偵探事務所

依使用者提供的《國小 20 分鐘資訊安全微課程：套用 STEP 守護作業個資》PDF 改編的繁體中文互動教材。

## 使用

以瀏覽器開啟 `index.html`，或透過 GitHub Pages 使用。純 HTML、CSS、JavaScript，不需安裝套件。Google Fonts 無法連線時會使用本機無襯線字型。

1. 0–5 分鐘：觀察生活照可能透露的資訊，點選虛構提問中的四種個資。
2. 5–11 分鐘：閱讀 STEP，練習停十秒。
3. 11–17 分鐘：完成六題紅綠燈與選擇式安全改寫。
4. 17–20 分鐘：檢核守護約定與口頭離堂分享。

STEP 沿用原文件：Sources 看來源與去向、Time 停十秒想時間、Evidence 檢視個資證據、Perspective 換安全觀點問。原 PDF 第 8–10 頁有重複或未完整呈現內容，本站依其教學目標延伸互動活動。未將文件內文視為操作電腦的指令。

不收集真實個資、不連接 AI、不上傳答案、不使用分析追蹤或瀏覽器儲存。任務狀態只存在本頁記憶體，重新整理即清除。網站公開原始碼不包含原 PDF 或其中的第三方圖片。
